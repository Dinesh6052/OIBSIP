# 🎮 Number Guessing Game

A simple and interactive Java console-based Number Guessing Game developed as part of the Oasis Infobyte Java Development Internship.

## 📌 Objective

The computer generates a random number, and the player tries to guess the correct number. After every guess, the program provides hints such as:

- Too High!
- Too Low!
- Correct!

The player must guess the number within the maximum number of attempts.

---

## 🚀 Features

- 🎲 Random number generation
- 🔢 Multiple difficulty levels
- 📈 Easy, Medium, and Hard modes
- ⬆️ Too High hint
- ⬇️ Too Low hint
- ✅ Correct answer detection
- 🔢 Attempt counter
- 🚫 Maximum attempt limit
- ❌ Game over message
- 🔄 Play Again option
- 🏆 Score tracking
- 🔁 Multiple rounds
- ⚠️ Input validation

---

## 🎯 Difficulty Levels

| Level | Number Range | Maximum Attempts |
|-------|-------------|------------------|
| Easy | 1 – 50 | 10 |
| Medium | 1 – 100 | 7 |
| Hard | 1 – 200 | 5 |
