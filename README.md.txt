# Oasis Infobyte Internship Projects

This repository contains the projects completed as part of the **Oasis Infobyte Internship Program (OIBSIP)**.

## ☕ Java Development

### Task 2 — Number Guessing Game 🎮

A Java console-based game where the system generates a random number and the user tries to guess it.

#### Features

- Random number generation
- Difficulty levels
- Attempt counter
- Higher/Lower hints
- Maximum attempts
- Score tracking
- Multiple rounds
- Play Again option

📁 Project Folder:

```text
Java-Task2-NumberGuessingGame
```

### Task 3 — ATM Interface 🏧

A Java console-based ATM simulation developed using Object-Oriented Programming.

#### Features

- User authentication
- PIN verification
- Maximum login attempts
- Withdraw money
- Deposit money
- Transfer money
- Transaction history
- Balance validation
- Object-Oriented Programming

📁 Project Folder:
